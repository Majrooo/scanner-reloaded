# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.3.x   | ✅ Yes             |
| < 0.3.0 | ❌ No              |

Only the latest release is actively supported. We recommend always using the newest version from the [Releases page](https://github.com/Majrooo/scanner-reloaded/releases).

## Reporting a Vulnerability

**Please do NOT open a public issue for security vulnerabilities.**

To report a security problem, email the maintainer directly:

**Email:** `security@scanner-reloaded.dev` *(placeholder — replace with your real contact)*

Alternatively, if you have one, use **GitHub's private vulnerability reporting**:

1. Go to the repository's **Security** tab
2. Click **"Report a vulnerability"** → **"New draft security advisory"**
3. Fill in the form (affected version, description, impact, and if possible a proof of concept)

### What happens next

- You will get an acknowledgement within **48 hours**
- The report will be handled confidentially — it will not be shared publicly until a fix is released
- After a fix or a decision, we will create a security advisory and, if needed, a patched release

## Scope

- The Rust backend (`src-tauri/`)
- The frontend (`src/`)
- The release workflow (`.github/workflows/release.yml`)

## Out of scope

- Third-party dependencies (report those to their respective projects)
- Issues already fixed in the latest release (upgrade first)
